# Fase 4 · análisis consolidado

`F4_Consolidado_Proyecto.ipynb` es el notebook ejecutable de la Fase 4. Retoma las tres preguntas de F1, valida la salida preparada por F2, reutiliza la clase y las mediciones de F3 y presenta resultados, pruebas exploratorias y límites de interpretación. Las cuatro imágenes de `figuras/` se generan al ejecutar el notebook: tres responden las preguntas del proyecto y el mapa de calor complementa el análisis mensual. También genera dos [mapas regionales interactivos](mapas/README.md) como material exploratorio adicional.

Para reproducirlo, abra la raíz del repositorio en VS Code y cree `.venv` con `requirements.txt` como explica el README principal. Seleccione el Python de esa `.venv` en el selector de kernel; no se guíe solo por un nombre de kernel registrado en otra carpeta. Ejecute F2 para crear `data/processed/nacimientos_preparados_propuesta.csv`. Luego abra este notebook, reinicie el kernel y use **Run All**. La primera celda verifica las dependencias; las siguientes validan 735.611 registros, los metadatos y la equivalencia con F3. Los CSV grandes son locales y no se incluyen en los commits.
